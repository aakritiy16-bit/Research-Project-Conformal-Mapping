# Numerical Methods for Conformal Mapping

*Author*: Aakriti Yadav
*Project*: 2nd Semester Research Project

### *About*
This repository contains my complete research work on Numerical Methods for Conformal Mapping. 
The thesis report is written in LaTeX. All results and graphs were generated using Python and MATLAB.

### *Folder Structure*
.
├── Applications_of_Conformal_Map...pdf  # Final Thesis PDF
├── main (1).tex                         # LaTeX source
├── _.py                                 # Python codes
└── _.png                                # Result figures

### *How to Reproduce*
1.  *Report*: Open Applications_of_Conformal_Map...pdf or compile main (1).tex
2.  *Code*: Run Python files like python sutherland.py
3.  *Figures*: All result graphs are in .png format

### *Key Contributions*
- Numerical implementation of Joukowski and Karman-Trefftz transformations
- FEM based solution for Conformal Mapping  
- Validation of results with high accuracy
